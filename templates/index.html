Every emergency triggers a fully automated multi-step pipeline across AI, voice, and data systems.

01

Hospital Request

Hospital submits an emergency blood request via REST API with blood group, urgency level, and patient details.

02

n8n Orchestration

Webhook triggers n8n workflow engine which coordinates the full response pipeline and monitors outcomes.

03

Donor Discovery

Compatible blood groups resolved via ABO/Rh matrix. Available donors fetched from database instantly.

04

AI Ranking

GPT-4o-mini ranks donors by proximity, response history, fatigue level, reliability, and response speed.

05

Voice Outreach

VAPI AI initiates personalised outbound voice calls to top-ranked donors with natural conversation.

06

Response Tracking

Webhook callbacks update donor status in real time. Accepted donors trigger hospital confirmation instantly.

Capabilities
Built for real
emergencies

Every component is designed for reliability under pressure, with fallbacks at every layer.

🧬

Blood Compatibility Engine

Full ABO/Rh compatibility matrix. O- universal donors are automatically surfaced for any blood type request. Zero manual lookup required.

📍

Haversine Geospatial Ranking

Great-circle distance calculated for every donor against the requesting hospital. Nearby donors are strongly prioritised — proximity accounts for 30% of the AI score.

🤖

GPT-4o-mini Donor Ranking

AI evaluates each candidate across 5 weighted factors: proximity, response probability, fatigue, donation history, and response speed — with written rationale per decision.

📞

VAPI AI Voice Calls

Outbound AI voice calls with personalised scripts. ElevenLabs synthesis, GPT conversation handling, and automatic yes/no response detection from transcripts.

⚡

Graceful Degradation

If OpenAI is down, a deterministic local ranking algorithm takes over. n8n and Supabase failures are logged but never block the core pipeline.

🔄

Real-Time Webhooks

VAPI and n8n post status callbacks in real time. Call outcomes update donor availability, request status, and trigger escalation logic automatically.

REST API
Simple, powerful endpoints

All emergency coordination happens through clean JSON APIs.

POST /api/emergency/

Submit an emergency blood request. Triggers the full AI coordination pipeline immediately.

GET /api/emergency/<id>/

Poll real-time status of an emergency request including all donor outreach attempts.

GET /api/donors/

List all active registered donors with blood group, location, and availability status.

POST /api/donors/

Register a new donor with GPS coordinates, blood group, and contact details.

PATCH /api/donors/<id>/

Update donor availability status or log a new donation to update fatigue scoring.

POST /webhooks/vapi/

VAPI call status callback. Processes donor responses and updates request state in real time.
